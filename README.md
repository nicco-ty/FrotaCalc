# FrotaCalc

Sistema desenvolvido em linguagem C para análise de consumo de combustível de motoristas e trechos percorridos.

## Funcionalidades

- Cálculo de consumo médio por motorista
- Cálculo de consumo médio por trecho
- Classificação de desempenho dos motoristas
- Relatórios individuais e gerais
- Validação de entrada de dados
- Cálculo do custo total de combustível
- Contagem de classificações
- Média e classificação geral

## Tecnologias utilizadas

- Linguagem C
- Biblioteca stdio.h

## Objetivo

Projeto desenvolvido para a disciplina de Algoritmos e Lógica de Programação com foco na prática de estruturas condicionais, estruturas de repetição e cálculos em linguagem C.
